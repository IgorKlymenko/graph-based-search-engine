# Proposals

The one page in this wiki that holds opinions. Everything else is fact. Each
row cites the evidence it rests on (a file, an ADR entry, a measured number) so
it can be checked, and an effort guess (**S** hours, **M** days, **L** weeks).
When a proposal is decided, record it as an ADR entry and change its status
here to *accepted → ADR x.y* or *rejected: reason*. Do not implement from this
page without that step for anything larger than **S**.

Written 2026-09-17 while producing the wiki. Ordered within each section by
value, not by effort. Rows marked **measured** were tested as mini-experiments
the same day; the numbers and caveats are in [experiments.md](experiments.md).
